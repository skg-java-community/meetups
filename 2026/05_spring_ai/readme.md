# Event Title

### Spring AI in Action: AI-Powered Java Apps with Spring Boot

## Topic Description

Hello Everyone!
We are excited to invite you to our next meetup, where we will dive into the world of AI-powered applications built with Java and Spring Boot! 🚀

### Topic
AI is rapidly becoming part of everyday applications, but how can Java developers actually use it in real-world systems? You don't need to switch stacks. Spring AI brings LLM integration directly into the Spring ecosystem you already know.

In this fully live-coded session, we will progressively build an "AI Assistant" from scratch, exploring:

- How to use Spring AI's ChatClient to talk to LLMs (OpenAI, Anthropic) from Spring Boot
- Structured Output — getting the AI to return typed Java records, not just strings
- Function Calling — letting the AI call your business logic and book real appointments
- Chat Memory — multi-turn conversations that remember context
- MCP Server — exposing your Spring Boot app as a tool for external AI clients like Claude
- A quick LangChain4j comparison to see the alternative approach

💡 This is a hands-on, code-first session with minimal slides. You will walk away with practical knowledge and a fully working project you can clone, run, and experiment with!

### 🎤 Speaker
This time, I, [Eleftherios Chrysochoidis](https://www.linkedin.com/in/lefterisxris/), Tech Lead @Chubb, will be taking the stage! I will live-code the entire demo, building the application step by step and showing how Spring AI turns regular Spring Beans into AI-powered agents.

🎯 Whether you are a Java developer curious about AI, already experimenting with LLMs, or wondering how MCP fits into the picture, this session will give you a good path to bringing AI into your Spring ecosystem.
