# Event Title

### Java Caching: From HashMap to Redis

## Topic Description

Hello Everyone!

A new season of our SKG Java Meetup begins, and we are ready to kick off! 🚀

For our first meetup of the season, we are diving into one of those topics that every backend developer uses at some point:
Caching in Java!

### Topic
Caching sounds simple: store something expensive once and reuse it.

In practice, though, things get interesting very quickly.
Where should the cache live? How long should data stay cached? What happens when the application runs on multiple instances? When should we use an in-memory cache such as Caffeine, and when does a distributed cache like Redis make more sense? And what happens behind Spring's @Cacheable annotation?

In this session, we will explore caching from the simplest implementation all the way to production-ready approaches. We will build the examples progressively, starting from a simple cache implementation and moving towards Caffeine, Redis and Spring Cache, while looking at what changes and what does not in our application code.

💡 This will be a presentation and hands-on session, with several switches from slides directly into the IDE. The goal is not just to see caching APIs, but to understand the engineering decisions and trade-offs behind them.
